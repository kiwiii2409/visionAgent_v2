# Linux System Settings

## Opening System Settings

1. Press the **win** key to open the application overview
2. Type **"Settings"** to search for the application in the top search bar
3. Press **Enter** or click the "Settings" app icon in the search results to launch the control center

## Changing Settings via the UI

1. In the Settings window, use the left sidebar to navigate to the relevant category (e.g., Network, Displays, Sound, Appearance, Users)
2. Click on the category to view its options in the main panel on the right
3. Adjust the necessary settings by clicking toggle switches, selecting from dropdown menus, or moving sliders
4. Changes are typically applied automatically and immediately as you interact with the controls — there is usually no "Save" button

## Important Notes

- Do NOT use terminal tools or command-line utilities if the task explicitly requires changing settings through the UI
- If you cannot find a specific option in the sidebar, click the Search icon (magnifying glass) at the top left of the window and type the name of the setting
- Some system-level changes (like adding a new user account or modifying the date/time) may be greyed out or restricted. Look for an **"Unlock"** button, click it, and enter the administrator password before making changes
- Navigate and toggle settings primarily using the mouse rather than relying on keyboard shortcuts
